UPDATE THE FIGHTER LEVEL GENERATION SYSTEM

The current fighter level generation is too random.

Fix the system so fighter levels are loosely determined by ranking.

IMPORTANT:

Rank should NOT directly equal level.

Do NOT make:

Rank 100 = Level 100
Rank 500 = Level 500

Instead, rankings determine allowed level ranges.

The goal:

- Lower ranked fighters should generally be lower level.
- Higher ranked fighters should generally be higher level.
- There should be subtle variation within each rank range.
- A Level 1 Career Player should never encounter extremely high-level opponents early.
- The Champion remains the only guaranteed Level 1000 fighter.

RANKING DOES NOT DIRECTLY CONTROL MATCHMAKING

Do not match the player based only on level.

The opponent selection system already uses rankings.

However, level ranges must prevent unrealistic matchups.

A Level 1 player should primarily see:

- Rank 700
- Rank 699
- Rank 698
- Nearby opponents

They should not see:

Level 200 fighters while still ranked near 700.

FINAL VALIDATION

After generating fighter levels:

Check:

- Rank 700 fighters are Level 1-5.
- Rank 651-699 fighters are Level 5-25.
- No low-ranked fighter has an extremely high level.
- Rank 1 Champion is Level 1000.
- Levels increase generally upward through the rankings.
- Variation exists inside each rank bracket.
- The Career Player's early progression is fair.

The final system should create a natural difficulty curve where the player climbs through increasingly stronger opponents instead of randomly encountering elite fighters at the bottom of the rankings.
